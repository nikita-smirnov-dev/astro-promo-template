# Юбилейное Промо-Приложение для Рок-группы "Silence Tends To Destroy"

Полноэкранное SPA (Single Page Application) промо-приложение, созданное специально к 10-летнему юбилею музыкального релиза рок-группы. Проект разработан как интерактивная цифровая карточка релиза, адаптированная под мобильные и десктопные устройства.

## Особенности проекта

Полноэкранное многостраничное веб-приложение (с эффектом плавных переходов), созданное специально к 10-летнему юбилею музыкального релиза рок-группы. Проект разработан как интерактивная цифровая экосистема релиза, полностью адаптированная под мобильные и десктопные устройства.

- **Современный роутинг (Astro Transitions)**: Переход с архитектуры хэшей на полноценный `ClientRouter`. Обеспечивает бесшовное переключение между страницами без перезагрузки экрана с сохранением состояния приложения и плавной анимацией переходов.
- **Интерактивная Галерея**: Адаптивный слайдер на базе Swiper с кастомной фракционной пагинацией, поддержкой управления с клавиатуры и полной доступностью (A11y) для скринридеров. Просмотр полноразмерных фото реализован через Fancybox.
- **Панель управления (Dashboard)**: Добавлен закрытый/внутренний интерфейс для управления контентом и просмотра расширенной информации о релизе.
- **Синхронизированный Музыкальный Плеер**: Полнофункциональный аудио-плеер с единым аудио-движком. Управление треками доступно как из основной медиа-панели, так и через компактный виджет, который автоматически появляется при навигации по сайту.
- **Строгая валидация данных (Zod)**: Вся информация о релизе, фотогалерее, трек-листе и метаданных валидируется с помощью Zod-схем, что обеспечивает 100% безопасность типов (Type Safety) данных на этапе сборки.

## Стек технологий

- **Фреймворк**: [Astro] (с поддержкой View Transitions)
- **Язык**: [TypeScript]
- **Слайдер и Галерея**: Swiper API (A11y модули) + Fancybox
- **Стилизация**: Sass / SCSS
- **Валидация данных**: [Zod]
- **Иконки**: `astro-icon`

## Команды для запуска

Все команды выполняются из корня проекта через терминал:

Установка зависимостей:

```bash
npm install
```

Запуск development сервера:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```

Предпросмотр production build:

```bash
npm run preview
```
